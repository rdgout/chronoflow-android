# Strings and copy (en + nl)

Phase 0c. Verified 2026-11-17 against iOS `f391a1fa` (`tools/ios-pin.txt`).

## Pipeline

| Command | Does |
|---|---|
| `make strings` | `tools/l10n/xcstrings2android.py`: reads the 13 iOS String Catalogs at the pin (`git -C $IOS_REPO cat-file` and `show` only), writes the string XML, `CopyIndex.generated.kt` and the lock. |
| `make plan-copy` | `tools/l10n/plan_copy.py`: copies iOS `PlanCopy.json` byte for byte to `core/plan/src/main/resources/plan_copy.json` and writes `tools/l10n/plan_copy.sha256`. |
| `make strings-check`, `make plan-copy-check` | The `--check` modes, part of `make generators-check`. `strings-check` also runs the `tools/l10n` unit tests (`make quick` runs them through `Scripts/test_scripts.sh`). |

`IOS_REPO` defaults to `/Users/rickgout/Sites/chronoflow-ios`. The check needs the iOS repo only to read the pin; it never reads the working tree.

Outputs (all in `:core:ui` unless noted): `values{,-nl}/strings_ios.xml`, `values{,-nl}/strings_android.xml` (overlay), `src/debug/res/values{,-nl}/strings_ios_debug.xml`, `values/strings_untranslatable.xml` (hand-written), `l10n/generated/CopyIndex.generated.kt`, `tools/l10n/names.lock.json`, and `core/plan/.../plan_copy.json`. `StringResourceLocationTest` (Konsist) fails if any other file holds strings.

## Rules for later phases

- Read resources with `stringResource(R.string.x, ...)` and `pluralStringResource(R.plurals.x, count, ...)` from `net.chronoflow.core.ui.R`. Use the generated name; never `getIdentifier`.
- Wizard `_one` plurals: pick the quantity as iOS does (`WizardStrings.swift:13-16`): `if (countText == "1") 1 else 2`, pass `countText` as `%1$s`, never a truncated `Double`.
- Auth `<terms>` and `<privacy>` arrive as literal tags. A small parser builds an `AnnotatedString` with `LinkAnnotation.Url`.
- `CopyIndex.find` returns `null` for an unknown runtime key, for the debug route and for the three replaced reminder steps. Callers show the same generic fallback as iOS, never the raw English server sentence.
- A key that iOS replaces with one overlay entry (the 2FA intro, the passkeys intro) resolves to the overlay through `CopyIndex.find(<iOS table>, <iOS key>)`.
- Background work resolves the language explicitly, never from the process locale.
- Hand-written `translatable="false"` names go into `strings_untranslatable.xml`; the generator reads them as reserved.
- Use `app_debug_route_x` only from `src/debug` source sets (OQ-0c-4).
