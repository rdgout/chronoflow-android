## 1. Goal

After the flights (and Coming back?), a traveller whose sleep is not on file sees **"How do you usually sleep?"**: a card with Usual bedtime and Usual wake-up time pills, then "When do you naturally feel most awake?" with four chronotype cards (Early bird, In between, Night owl, Not sure). A time pill opens a bottom sheet with the Material time dial; **Done rounds the time to the nearest 5 minutes** and writes it. Continue checks that the night is 3–14 hours long, otherwise it shows "Check your bedtime and wake-up time." and stays.

When the server review asks blocking questions, the app shows them one per screen under the eyebrow "A few quick questions": **age group** (Under 18 / 18–64 / 65 or older) and **shift work** (No / Yes), in the server's wording, with a why-line and (guest, age only) the medical disclaimer. A tap moves on after 250 ms. These two are the **only** questions; the five retired health questions are never built. A larger-text variant keeps the options tall enough.

When the review answers `no_plan`, **"No plan available"** shows the server reasons in a dawn notice card and a note that depends on context (default, "you gave this answer on an earlier trip", or editing), with **Change my answers** and **Close**.

The **free-day times** sheet ("Sleep on free days": Same as work days / Different times + Bedtime and Wake-up pills) is built as the first kind of the shared fine-tune answer sheet, which 9f then extends.

Done means:
- Bedtime, wake-up and the two free-day times are written only by Done, as `HH:mm`, rounded to 5 minutes (`WizardClockRounding`, JVM-tested). Flight times (9d) keep minute precision.
- The sleep step, the two questions, the excluded screen and the free-day sheet render from the 9a state, drive only 9a model functions, and use only generated resources and plan-copy catalog lines.
- Every listed board is seeded, guarded in Robolectric and captured; one seeded emulator class proves the time sheet keeps the app language and the phone's 12/24-hour setting.
- A Konsist rule proves no retired health question or field is referenced.

## 5. The spec

### 5.1 Clock rounding (new, `:core:wizard`, pure Kotlin) [R; OQ-A8]

File `…/cw/model/WizardClockRounding.kt`:

```kotlin
object WizardClockRounding {
    const val STEP_MINUTES = 5
    /** Nearest multiple of 5 minutes, wrapping past midnight. Returns "HH:mm". */
    fun roundToStep(hour: Int, minute: Int): String?
}
```

- Returns `null` when `hour !in 0..23` or `minute !in 0..59`.
- `total = hour * 60 + minute`; `rounded = ((total + 2) / 5) * 5 % 1440` (remainders 0–2 round down, 3–4 round up; integer minutes have no tie).
- Output zero-padded without `String.format`: `"${h / 10}${h % 10}:${m / 10}${m % 10}"`.
- Examples: 07:12 → `07:10`; 07:13 → `07:15`; 07:15 → `07:15`; 00:02 → `00:00`; 12:03 → `12:05`; 23:57 → `23:55`; **23:58 → `00:00`**; 0:0 → `00:00`.
- `fun change(stored: String?, hour: Int, minute: Int, touched: Boolean): String?` — `null` when `!touched` or `roundToStep(hour, minute) == stored`, else the rounded value (§5.3).
- Applies to `habitual_bed`, `habitual_wake`, `free_day_bed`, `free_day_wake` only. Flight times (9d) never use it.
